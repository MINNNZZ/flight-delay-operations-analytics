# Publication notes

This repository is a selected public copy of one completed local aviation project. Resumes, contact information, agent instructions, local skill installations, credential files, Python caches, Power BI caches and historical workspace-reorganization archives are excluded.

Local user/workspace paths in text source and report definitions were replaced with a neutral project-path placeholder. Set your own path before refreshing Desktop. Embedded PBIX models preserve the verified data and formulas; refresh-source locations inside those models may still need updating in Power Query. Such local source locations are not credentials.

Public profiling and validation scripts do not require a private workspace AGENTS.md. The old instruction-file hash retained in historical manifests is not a dataset identity; new profiling records only source CSV hashes. Verification logs describe the original analysis/desktop executions, not a new run of the full pipeline on GitHub. Original artifact hashes in those logs can differ from sanitized documentation hashes.

The 13 KB empty Desktop template is retained as a build fixture. Large embedded PBIX deliverables remain local pending explicit embedded-data distribution approval; they are not attached to the source-only release. Raw and cleaned flight CSVs are excluded; small aggregate/dimension tables and screenshots are included to explain the work.

There is no claim that a dataset license was independently verified. No open-source license was selected on behalf of the owner; third-party materials retain their applicable terms. The published code includes AI-assisted work; see README for the scope of that assistance.
